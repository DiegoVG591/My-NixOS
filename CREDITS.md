# Credits

This repo builds on the following external work:

- **conf/hypr/modules/hyprlock-eq/** — Fubi118's hyprlock equalizer
  and now-playing widgets (github.com/Fubi118/hyprlock-eq)
- **scripts/DNX_Convert.sh** — base structure adapted from
  NapoleonWils0n's dnxhd-pcm (github.com/NapoleonWils0n/nixos-bin)
- **zsh/themes/cool-cats.zsh-theme** — base structure adapted from
  oh-my-zsh's robbyrussell theme
  (github.com/ohmyzsh/ohmyzsh/blob/master/themes/robbyrussell.zsh-theme)
- **conf/waybar/** — adapted from a waybar/Hyprland setup
  ThePrimeagen showed while streaming his migration to Arch Linux
  (stream-only, no public repo to link)
- **conf/easyeffects/output/DefaultPreset.json** — values taken from
  Digitalone1's "Loudness Equalizer" preset (LoudnessEqualizer.json,
  github.com/Digitalone1/EasyEffects-Presets), entered by hand in
  EasyEffects 8.2.5. MIT licensed; the license notice is kept in
  conf/easyeffects/LICENSE-Digitalone1. That repo credits its Perfect
  Equalizer stage to Ziyad Nazem.
